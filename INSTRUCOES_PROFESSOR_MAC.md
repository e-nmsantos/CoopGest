# CoopGest - instrucoes para macOS

Esta versao corre localmente no Mac atraves do browser. Nao precisa de instalar Node.js nem compilar o frontend.

## Como abrir

1. Descompacte o ficheiro ZIP.
2. Abra a app Terminal no Mac.
3. Arraste a pasta descompactada para a janela do Terminal, ou entre nela com `cd`.
4. Execute:

```bash
bash abrir_no_mac.command
```

Na primeira execucao, o script cria um ambiente Python local e instala as dependencias. Depois abre a aplicacao no browser em:

```text
http://127.0.0.1:8000
```

Feche a janela do Terminal ou prima `Ctrl+C`.

Se o Mac nao tiver Python 3 instalado, instale-o a partir de:

```text
https://www.python.org/downloads/macos/
```
